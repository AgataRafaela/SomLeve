# 🌙 Hora do Descanso — Som Leve

Um ambiente sonoro tranquilo para momentos de relaxamento 💜

O **Hora do Descanso** é um projeto desenvolvido com o objetivo de proporcionar uma experiência visual acolhedora e intuitiva para quem deseja criar uma atmosfera de tranquilidade por meio de sons ambientes

Com uma interface delicada, o projeto combina desenvolvimento front-end e recursos de áudio do navegador para oferecer uma experiência relaxante e agradável :)

## ✨ Funcionalidades

-  **Biblioteca de sons:** diferentes opções de sons ambientes para criar combinações relaxantes
- **Controles de reprodução:** botões para reproduzir, pausar e navegar entre os sons
- **Controle de áudio:** estrutura para ajustar a experiência sonora
- **Temporizador:** recurso de tempo para sessões de descanso
- **Favoritos:** possibilidade de marcar sons favoritos e manter as preferências salvas no navegador
- **Interface responsiva:** adaptação da experiência para diferentes tamanhos de tela
- **Áudio no navegador:** utilização da Web Audio API para trabalhar com recursos de áudio

## 🛠️ Tecnologias utilizadas

- **Next.js**
- **React**
- **TypeScript**
- **SCSS**
- **Web Audio API**
- **Local Storage**
- **Git e GitHub**
